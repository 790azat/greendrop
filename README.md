# GreenDrop — сервис выноса мусора

PWA-приложение (iPhone, Android, веб) с тремя кабинетами:

- **Клиент** (`/client`): фото мешков у двери, адрес (улица, дом, подъезд, этаж, квартира, домофон), количество и размер мешков, время, оплата, отслеживание заказа с фотоотчётом, оценка исполнителя.
- **Исполнитель** (`/worker`): лента новых заказов, принятие заказа, пошаговый чек-лист с галочками и обязательными фото (у двери → забрал → выбросил), звонок клиенту, маршрут, заработок.
- **Админ** (`/admin`): статистика, все заказы, назначение/снятие исполнителя, отмена, одобрение и блокировка исполнителей, клиенты, тарифы.

## Стек

Next.js 15 (App Router) + Postgres (Neon) + Vercel Blob для фото. Без базы данных приложение работает в демо-режиме (встроенный PGlite, данные временные).

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `DATABASE_URL` | Postgres (Neon). Создаётся автоматически при подключении Neon в Vercel → Storage |
| `BLOB_READ_WRITE_TOKEN` | Vercel Blob для фото. Без него фото хранятся в базе |
| `ADMIN_PASSWORD` | Пароль входа в `/admin` (по умолчанию `admin123`) |
| `SESSION_SECRET` | Секрет для подписи сессий |

## Локальный запуск

```bash
npm install
npm run dev
```

## Установка на телефон

Откройте сайт → iPhone: Safari → «Поделиться» → «На экран „Домой“». Android: Chrome → ⋮ → «Установить приложение». Подробно на странице `/install`.

## Возможности (v2)

- Вход по SMS-коду (Twilio: `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM`; без ключей код показывается на экране) и по PIN.
- Демо-вход в один клик (клиент / исполнитель / админ) и демо-данные. Отключить: `DISABLE_DEMO=1`.
- Подписки на регулярный вынос (дни недели и время, скидка), заказы создаются автоматически (cron `/api/cron` + при открытии приложения).
- Онлайн-оплата Idram / ArCa / Telcell в демо-режиме, чаевые исполнителю.
- Push-уведомления (Web Push, ключи `NEXT_PUBLIC_VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`).
- Карта (OpenStreetMap), геолокация клиента и исполнителя, сортировка заказов по расстоянию, карта для админа.
- Районы с доплатами, промокоды, реферальная программа и бонусы.
- Услуги: бытовой мусор, вторсырьё, крупногабарит.
- Подготовка к App Store / Google Play: см. `docs/MOBILE-APPS.md`.

## Хранение данных без базы

Если `DATABASE_URL` не задан, приложение использует встроенный PostgreSQL (PGlite) в памяти и сохраняет
JSON-снимок всех таблиц в Vercel Blob после каждого изменения. Этого достаточно для демо и тестов.
Для реальной работы подключите Neon: Vercel → проект → Storage → Create Database → Neon.
